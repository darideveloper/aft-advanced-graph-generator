# AFT — Advanced Graph Generator (Astro)

SSR bar chart visualization microservice of the **AFT (Alfabetización Tecnológica / Tech Literacy)** ecosystem, built for **LeadForward Global Solutions**. Renders horizontal bar charts of competency results, receiving data via URL from the dashboard.

## Tech Stack

- **Astro 5 + Node SSR** — Server-side rendered framework
- **Tailwind CSS** — Utility styling with corporate color palette

## Features

- "Resultados por tema" chart with per-competency scores
- Vertical reference lines at positions 4, 7, 10 (1–10 scale)
- Average marker per bar and dynamic subtitle
- Dynamic scaling based on actual data range (min/max)
- 13-color cycle (tech-orange, tech-green, tech-blue)

## Setup

```bash
cp .env.example .env
# Configure API_ENDPOINT, API_TOKEN, BAR_CHART_SURVEY_ID
npm install
npm run dev
```

# AFT — Advanced Graph Generator (Astro)

Microservicio SSR de visualización de gráficas de barras del ecosistema **AFT (Alfabetización Tecnológica)**, desarrollado para **LeadForward Global Solutions**. Renderiza gráficas horizontales de resultados por competencia, recibiendo datos vía URL desde el dashboard.

## Tech Stack

- **Astro 5 + Node SSR** — Framework con renderizado del lado del servidor
- **Tailwind CSS** — Estilos con paleta de colores corporativos

## Features

- Gráfico "Resultados por tema" con puntuaciones por competencia
- Líneas de referencia en posiciones 4, 7 y 10 (escala 1–10)
- Marcador de promedio por barra y subtítulo dinámico
- Escalado dinámico basado en el rango real de datos
- Ciclo de 13 colores (tech-orange, tech-green, tech-blue)

```bash

# Configurar API_ENDPOINT, API_TOKEN, BAR_CHART_SURVEY_ID
```
